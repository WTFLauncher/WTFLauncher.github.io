# wtflauncher.github.io

WTF Launcher 的官网源码，发布在 https://wtflauncher.github.io/ 。

- 只有一个静态页面 `index.html`，没有构建步骤，改完推 main 即发布。
- 图标来自启动器仓库的 `program_info/`，副本放在 `assets/`。
- 页面末尾有一段写给 Mojang / Minecraft 应用审核方的英文说明，内容与启动器的实际实现一致；改功能描述时请同步核对启动器仓库，不要写没有实现的行为。

启动器仓库：<https://github.com/WTFLauncher/WTFLauncher>
